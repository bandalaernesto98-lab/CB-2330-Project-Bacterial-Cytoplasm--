# CB-2330-Project-Bacterial-Cytoplasm--
Final project for the CB-2330 based on the scientific paper publishhd by Ido Golding and Edward C. Cox (2006).

On this project, we worked with a reference value for the ratio of the sub diffusive coefficient of mRNA molecules observed on bacterial cytoplasm.

With said reference values we generated a stochastic model (using a Monte Carlo approach) to then calculate the MSD values of 300 molecules of the mRNA within tau (time range) to mimic the sub-diffusive behavior proposed on the research paper.

Once our model could correctly represent the expected diffusion behavior we used it to assess the impact of different parameters present in the diffusion of the molecule's behavior. 
Using these parameters, we estimated the range of "optimal" conditions for a sub diffusive behavior and also propose a defined range of average molecular displacement which was not mentioned in the paper.

Paper's URL: https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.96.098102
